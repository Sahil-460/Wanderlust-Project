# 🌍 Wanderlust 

A full-stack web application for listing and booking holiday rentals, built as my **first major full-stack project**. It features complete user authentication, dynamic database management, and interactive listings.

---

### 🚀 Key Features
* **Authentication & Authorization:** Secure user sign-up, login, and role-based access for managing listings and reviews.
* **Property Listings:** Full CRUD functionality to create, view, edit, and delete rental listings.
* **Reviews System:** Users can leave ratings and comments on properties.
* **Interactive UI:** Responsive design displaying property images and details seamlessly.

---

### 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap / EJS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Authentication:** Passport.js

---

### 💡 Key Takeaways
* Designed end-to-end RESTful APIs.
* Integrated MongoDB models and schemas for relational-like data structures.
* Implemented secure authentication flows and middleware authorization.
